# Stirling-Motor-Simulation
An interactive Python simulation of a Stirling engine featuring thermodynamic calculations, a pressure–volume diagram, and real-time mechanical animation.

An AI-assisted Python project exploring the simulation and visualization of a Stirling engine.

The application features an interactive desktop interface, thermodynamic calculations, a pressure–volume diagram, and a simple mechanical animation.

Technologies: Python, Tkinter, NumPy, Matplotlib.

Development approach: Built through a combination of personal coding, experimentation, and AI-assisted development.

Learning goals: Improve Python programming skills, explore numerical modeling, and develop interactive scientific visualizations.

*Note: This is an educational simulation. Its physical assumptions and estimated quantities have not all been independently validated against a real engine.*
